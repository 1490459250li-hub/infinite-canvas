新建技能

      
    

    

      
      
      
      

        技能就是一段可复用的提示词。保存后可在技能页一键套用到画布输入框，
        也可以导入别人的 SKILL.md（Codex / Claude 同类格式，读 YAML 头里的 name、description）。
      

    

    

      
      
    

  


  
  

    

      
添加 MCP 连接

      
    

    

      
      

        
        
      

      

        兼容主流写法：Claude / Cursor 的 mcpServers、Codex 的
        [mcp_servers.名字]，以及只给 url 的 HTTP / SSE 连接。
        本版本登记并校验配置、生成可复制的标准片段；工具调用要等本地 MCP 运行时就位后才会真正执行。
